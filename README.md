Локальное расширение для анализа стандартных шахматных позиций на [Lichess](https://lichess.org) и [Chess.com](https://www.chess.com). Встроенный HUD объединяет собственный JS-поиск, Stockfish 19 NNUE, дебютный справочник и визуальные объяснения ходов.

**Версия `15.8.0` промежуточная:** интерфейс, Script API, формат настроек и адаптеры сайтов ещё могут изменяться. Расширение устанавливается из исходников без bundler и `npm install`.

## Возможности

- Fast/Deep-анализ, локальный Stockfish, Syzygy, Cloud Eval и Explorer.
- Лучший ход, отдельная альтернативная («средняя») линия и худший ход при наличии подходящих вариантов.
- Стрелки, подсветка клеток, heatmap, оценка, PV, WDL и история анализа.
- ECO-справочник, русские пояснения, локальная Experience DB и настраиваемые темы HUD.
- Script API для собственных локальных модулей; [документация](CHESSCOACH_API_DOCS.md) и [пример](scripts/sample.js).
- Постоянная отметка официального бесплатного проекта и [локальная страница благодарностей](pages/credits.html).

| Платформа | Особенности |
| --- | --- |
| Lichess | DOM + WebSocket bridge, проверяемый premove, click/drag/hybrid |
| Chess.com | Адаптер открытых Shadow DOM, Bézier click/drag, T1 limiter, Privacy Mask |
| Браузер | Google Chrome 116+, Manifest V3; отдельного Firefox manifest нет |
| Интерфейс | HUD внутри страницы; «О проекте» доступен из HUD, кнопки расширения и его настроек |

Chess960 и другие варианты не поддерживаются. Другие Chromium-браузеры могут запускать расширение, но совместимость с ними отдельно не подтверждена.

## Установка

1. Получите исходники этого репозитория; объявления о бесплатных сборках ищите в [официальном канале](https://t.me/chesscoach_dev).
2. Откройте `chrome://extensions/`.
3. Включите режим разработчика.
4. Нажмите `Загрузить распакованное расширение`.
5. Выберите каталог проекта, в котором находится `manifest.json`.
6. Перезагрузите уже открытые вкладки Lichess и Chess.com.

Первая инициализация Stockfish может занять время. Файлы в `vendor/stockfish/` и `lib/stockfish-local.js` нужны для работы движка, а не являются мусором или кешем: не удаляйте их из устанавливаемой копии.

Для чистой папки распространения без вложенного Android-проекта, Git-служебных файлов и ключей используйте Node.js 22/24:

```bash
node scripts/package-extension.cjs
```

Готовая папка: `dist/chesscoach-extension/`. Её можно загрузить распакованной или архивировать её содержимое. Служебные файлы и личные конфигурации не следует добавлять к архиву.

## Честная игра

Используйте ChessCoach для обучения, разбора завершённых партий и только в режимах, где помощь движка разрешена правилами площадки. Подсказки, автоходы и проверяемый premove против других игроков могут нарушать [правила Lichess](https://lichess.org/terms-of-service) и [Chess.com](https://www.chess.com/legal/fair-play) и привести к блокировке аккаунта.

Названия `legit`, `stealth`, `anti-ban`, настройки задержек и T1 limiter **не гарантируют защиту от обнаружения или бана**. Privacy Mask тоже не делает использование движка допустимым.

## Движок и линии

Fast pass проверяет легальность и тактику, Deep pass углубляет JS-поиск, а локальный Stockfish уточняет результат. При подходящих условиях подключаются внешние источники. Ответы проверяются по позиции и поколению анализа, чтобы устаревший расчёт не заменял новый.

- Основной backend: `Stockfish.js 19.0.1`, full NNUE, один Worker в MV3 Offscreen Document и один поток.
- Full backend выбирается при `navigator.deviceMemory >= 8`; Hash обычно 32 или 64 МиБ. При нехватке ресурсов или ошибке загрузки используется Lite/ASM fallback.
- Полный WASM занимает около **94,57 МиБ**. Это обязательный runtime-ресурс; крупный размер не означает, что его можно исключить из исходной поставки.
- Средняя линия показывается только как отдельная легальная альтернатива. Если её нет, лучший ход не выдаётся за средний.
- Показ альтернативы сам по себе не включает её выполнение: настройки отображения и автохода независимы. `ENGINE MAX` и `HvH` используют только основную линию.
- `ENGINE MAX` ждёт основной ответ Stockfish и использует `MultiPV=1`; он не включает auto move самостоятельно и не гарантирует full NNUE на любом устройстве.

Ползунок `400-3000 ELO`, WDL, trap chance, T1 и premove confidence являются эвристиками, а не измеренным рейтингом или гарантированными вероятностями. Профили с именами шахматистов не копируют их модели и не означают их участия в проекте.

## Настройки и управление

Настройки, положение HUD и Experience DB сохраняются в `chrome.storage.local`. Experience DB хранит бонусы для `FEN + UCI`, а не обучает нейросеть. Общие настройки могут влиять на оба сайта.

Экспорт `.chess` содержит JSON с сигнатурой `CHESSCOACH_CONFIG_V15`; импорт принимает также `.json`. В файле могут быть личные настройки, фон и данные Privacy Mask. Экспорт **не шифруется**, строгой миграции между промежуточными версиями нет. Не публикуйте личные конфигурации.

| Клавиша | Действие |
| --- | --- |
| `Insert` | Показать или скрыть HUD |
| удержание `Alt` | Показать heatmap |
| `X` или `Ч` | Выполнить рекомендованный ход на Chess.com |
| `Ctrl+Shift+M` | Переключить Privacy Mask |
| `Escape` | Остановить активный матовый или аудиоэффект |

## Приватность и сеть

Движок упакован локально, но расширение **не полностью офлайн**:

- FEN позиции может передаваться в Lichess Cloud Eval, Masters Explorer и Syzygy.
- Peer-extension detector на Lichess использует `ntfy.sh`: идентификатор комнаты, случайный instance ID, цвет, профиль, UI-ELO, состояние auto move и timestamp.
- Заданный пользователем внешний URL аватара создаёт отдельный запрос к его хосту.

Manifest запрашивает `storage` и `offscreen`, а также доступ к указанным в нём HTTPS-хостам. Разрешений `cookies`, `tabs`, `webRequest`, `downloads` и `scripting` нет; это не превращает пользовательские скрипты в изолированную среду.

**Privacy Mask скрывает только отображение профилей при записи экрана.** Он не анонимизирует трафик, не удаляет данные из сайта и не является средством защиты учётной записи. Не прикладывайте cookies, токены или личные конфигурации к публичным отчётам.

## Script API

`lib/script-api.js` предоставляет `window.CC`: lifecycle hooks, состояние партии, UI, SVG/Canvas, CSS, WebAudio, локальное хранилище и учитываемые SDK таймеры. Локальные модули лежат в `scripts/`; после изменения файлов перезагрузите расширение и страницу.

**Sandbox и hot reload отсутствуют.** Скрипты имеют доступ к DOM и стандартным Web API в контексте content script. Запускайте только прочитанный и доверенный код. `onFrame` экспериментален и не гарантирует постоянные 60 FPS.

Документация: [CHESSCOACH_API_DOCS.md](CHESSCOACH_API_DOCS.md). Пример: [scripts/sample.js](scripts/sample.js).

## Проверки

Для тестов нужен Node.js 22 или 24, установка npm-зависимостей не требуется. Выполняйте из корня расширения:

```bash
node --test tests/*.test.cjs
node tests/credits.browser.cjs
```

После правок адаптеров дополнительно проверьте unpacked extension на обеих площадках в разрешённом режиме анализа. Модульные тесты не доказывают совместимость с любой будущей разметкой сайтов.

Проверка страницы благодарностей запускает установленный Chrome в отдельном временном профиле. Пути можно задать через `CC_BROWSER_CHROME` и `CC_BROWSER_TEMP`; основной профиль браузера не используется.

## Ограничения

- DOM-адаптеры зависят от разметки сайтов; закрытые Shadow DOM недоступны без публичного источника состояния.
- При открытии партии не с начальной позиции история, рокировка и en passant могут быть восстановлены не полностью.
- Full NNUE зависит от доступной памяти, а облачные источники и peer beacon от сети и внешних сервисов.
- Пользовательский код не изолирован; форматы настроек и экспериментальный SDK могут меняться.
